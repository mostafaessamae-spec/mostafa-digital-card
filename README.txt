MOSTAFA EL-HAYES — DIGITAL BUSINESS CARD

Preview:
- Open index.html in a browser.

Free publishing:
1. Create/sign in to a GitHub account.
2. Create a NEW public repository named: mostafa-el-hayes-card
3. Upload index.html, Mostafa-El-Hayes.vcf, and the assets folder (keep the folder structure).
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch", select "main" and "/ (root)", then Save.
6. GitHub will show your public page address, usually:
   https://YOUR-USERNAME.github.io/mostafa-el-hayes-card/

QR code:
After the page is published, create a static QR code pointing to that exact public URL.
Do not use a temporary preview URL. A static QR code can be generated free and will not need a subscription.
